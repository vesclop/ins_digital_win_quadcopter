# Местность и маршрут цифрового двойника

## Система координат и допущения

Местность синтетическая: это аналитическая модель, а не карта реального географического района.

- ось **X** направлена на восток, м;
- ось **Y** — на север, м;
- ось **Z** — вверх, м; координата Z является абсолютной высотой в условной системе высот;
- начало координат находится на старте;
- обычная высота полёта — **60 м над поверхностью**;
- карта покрывает участок примерно 5,65 × 0,9 км;
- базовая крейсерская скорость — 12 м/с, на манёврах — 4–7 м/с;
- посадка выполняется вертикально, поскольку носителем является квадрокоптер; требование трёх заходов относится только к самолёту.

## Описание местности

Рельеф состоит из пологих волн, трёх локальных холмов и речной долины:

1. **Запретная зона** с центром (600; 0) и радиусом 65 м.
2. **Три холма** с центрами по X = 1200, 1800 и 2400 м. Они задают препятствия для вертикальных облётов.
3. **Три участка горизонтального маневрирования** с центрами X = 3000, 3600 и 4200 м.
4. **Речная долина и стальной мост** с центром (4800; 0). Река проходит поперёк направления полёта. Нижняя плоскость пролёта моста находится на 35 м над поверхностью в его центре; дрон проходит на высоте 25 м, сохраняя номинальный запас 10 м.
5. **Посадочная площадка** с координатами (5450; 0).

Центры событий расположены через 600 м, то есть приблизительно равномерно по маршруту. Модель рельефа находится в `digital_twin/mission.py`.

## Модель полёта и навигации

Симуляция не использует ГНСС. Оценка состояния не присваивается напрямую по истинному положению или скорости: в `digital_twin/navigation.py` выполняется кватернионная механизация БИНС и комплексирование через **15-компонентный error-state EKF**. Вектор ошибок включает позицию, скорость, ориентацию и оценки смещений гироскопа и акселерометра.

Модель ICM-42688-P работает на 200 Гц и учитывает:

- остаточные смещения после начальной калибровки;
- паспортные спектральные плотности шума гироскопа и акселерометра;
- температурный дрейф и случайное блуждание смещений;
- масштабные и перекрёстные ошибки;
- ограничение диапазонов измерений.

В базовом сценарии используются только **ICM-42688-P, BMP390, IST8310 и доплеровский радар IWR6843AOP**. Реализации VIO, радиовысотомера и привязки по ориентирам сохранены, но по умолчанию отключены через `SimulationFeatures` в `digital_twin/configuration.py`.

Каналы:

- **IWR6843AOP, 20 Гц:** три доплеровских луча на частоте 62 ГГц, квантование радиальной скорости 0,234375 м/с, ошибка масштаба, шум 0,08 м/с, ухудшение до 0,25 м/с над водой и задержка 60 мс. Вектор скорости восстанавливается по трём проекциям с учётом ориентации. Подробности: `docs/Доплеровский_радар_IWR6843AOP.md`.
- **BMP390, 25 Гц:** давление, шум, поток винтов, температура и изменение фонового давления.
- **IST8310, 50 Гц:** курс с шумом и квантованием; у моста действует магнитная аномалия. Измерения с неправдоподобным модулем поля не передаются в фильтр.
- **VIO, необязательный модуль, 20 Гц:** ошибка масштаба со стандартным отклонением 0,8 %, шум 0,12 м/с, накапливающееся смещение и задержка 120 мс. При включении модуль временно теряет работоспособность над слаботекстурированным полем и в тени моста.
- **Радиовысотомер, необязательный модуль, 50 Гц:** шум 0,16 м, над водой — 0,3 м. Абсолютная высота восстанавливается по неточной карте рельефа.
- **Карта и ориентиры, необязательный модуль:** у каждого из восьми ориентиров выполняется одна попытка привязки, вероятность успеха 70 %. Координатное измерение имеет шум 2 м и проходит ковариационную проверку EKF.

Внешние условия включают постоянный ветер (0,45; −0,30; 0) м/с, случайные порывы, начальную ошибку выставки ориентации и координат. Модель остаётся учебной: динамика аппарата представлена ограниченным регулятором скорости, а не полной аэродинамикой моторов и рамы.

## Проверка результатов

Для базового seed 42 с отключёнными VIO, радиовысотомером и привязкой по ориентирам:

- СКО ошибки навигационной позиции — **7,24 м**, максимум — **12,97 м**;
- финальная ошибка — **12,91 м**;
- абсолютные коррекции положения отсутствуют;
- маршрут завершён без нарушения запретной зоны.

Дополнительная проверка seeds 42–44 дала СКО **7,24 / 4,77 / 6,54 м**; среднее СКО трёх прогонов — **6,19 м**, 95-й процентиль максимальной ошибки — **12,82 м**. Все три маршрута завершены без нарушения запретной зоны. Три прогона недостаточны для статистически надёжной оценки и служат только демонстрацией изменчивости результата.

Запуск из корня проекта:

```bash
python digital_twin/uav.py
```

Для повторения с другим случайным сценарием или серии испытаний:

```bash
python digital_twin/uav.py --seed 123
python digital_twin/uav.py --monte-carlo 10
```

Повторное включение сохранённых дополнительных модулей:

```bash
python digital_twin/uav.py --enable-vio --enable-radar-altimeter --enable-landmarks
```

Флаги можно использовать по отдельности.

Результаты сохраняются в `digital_twin/results/`:

- `simulation_result.png` — карта, идеальный и фактический маршруты, высота, скорость, ошибки и статистика;
- `route.csv` — координаты маршрута;
- `flight_log.csv` — телеметрия с шагом записи 0,1 с;
- `summary.json` — числовые показатели миссии и проверка каждого препятствия;
- `monte_carlo.json` — сводка серии, если использован аргумент `--monte-carlo N`.
