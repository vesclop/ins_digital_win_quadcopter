# Барометр Bosch BMP390

## Выбор модели

Для вертикального канала цифрового двойника выбран цифровой датчик абсолютного давления **Bosch Sensortec BMP390**. Он предназначен в том числе для стабилизации высоты дронов, имеет небольшие размеры и встроенные фильтрацию и FIFO.

Официальные источники:

- [страница BMP390 Bosch Sensortec](https://www.bosch-sensortec.com/en/products/environmental-sensors/pressure-sensors/pressure-sensors-bmp390.html);
- [datasheet BST-BMP390-DS002](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmp390-ds002.pdf);
- [product flyer BST-BMP390-FL000](https://www.bosch-sensortec.com/media/boschsensortec/downloads/product_flyer/bst-bmp390-fl000.pdf).

## Основные характеристики

| Параметр | Значение |
|---|---|
| Измеряемая величина | абсолютное атмосферное давление и температура |
| Диапазон давления с полной точностью | 300–1250 гПа |
| Абсолютная точность давления, типовая | ±0,50 гПа при 300–1100 гПа и 0…65 °C |
| Относительная точность, типовая | ±0,03 гПа, что соответствует примерно ±0,25 м высоты |
| RMS-шум в режиме наименьшей полосы и наибольшего разрешения | 0,02 Па |
| Температурный коэффициент смещения | ±0,6 Па/К при 25…40 °C и 900 гПа |
| Максимальная частота измерений | 200 Гц |
| Выходные данные | 24 бита |
| Интерфейсы | I²C, SPI |
| Питание VDD / VDDIO | 1,65–3,6 В / 1,2–3,6 В |
| Типовой ток при 1 Гц | 3,2 мкА |
| Корпус | LGA-10, 2,0 × 2,0 × 0,75 мм |
| Дополнительно | IIR-фильтр, FIFO на 512 байт, прерывания |

## Роль в проекте

Барометр измеряет давление, по которому вычисляется **барометрическая высота относительно точки взлёта**. В навигационном фильтре этот канал ограничивает вертикальный дрейф IMU. Высоту именно над землёй барометр не измеряет: для неё используются ToF и радар, а рельеф учитывается отдельно.

На маршруте BMP390 используется:

- при полёте по рельефу — совместно с высотомером и цифровой картой местности;
- при трёх облётах сверху — для контроля подъёма на половину текущей высоты;
- при пролёте под мостом — как резервный вертикальный канал, но не как единственный источник безопасной высоты;
- при посадке — совместно с ToF.

## Принятая модель в симуляции

Частота опроса принята **25 Гц**. Это ниже паспортного максимума и достаточно для вертикальной динамики выбранного сценария.

Модель в `digital_twin/sensors.py` учитывает:

- стандартную барометрическую зависимость давления от высоты;
- случайный шум давления;
- дополнительные возмущения от потока винтов;
- медленное изменение фонового давления;
- температурное смещение с коэффициентом 0,6 Па/К.

Шум 0,9 Па в коде является **консервативной настройкой выбранного рабочего режима**, а не паспортным значением 0,02 Па для режима наибольшего разрешения. Перед взлётом выполняется привязка к исходной высоте, поэтому моделируется прежде всего относительная, а не абсолютная точность.

## Ограничения

- Погодные изменения давления воспринимаются как изменение высоты.
- Поток от винтов и аэродинамические завихрения создают дополнительные помехи.
- Датчик нужно защищать от прямого набегающего потока, сохраняя при этом вентиляцию измерительной камеры.
- Одного барометра недостаточно для безопасного следования рельефу и пролёта под мостом.
