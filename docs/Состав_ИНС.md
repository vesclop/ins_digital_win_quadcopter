# Состав инерциальной навигационной системы БПЛА (DJI Mavic 3 Pro)

В разделе описано, из чего состоит инерциальная навигационная система (ИНС) БПЛА вертолётного типа на примере квадрокоптера DJI Mavic 3 Pro: какие датчики в неё входят, где они расположены, какие параметры измеряют, с какой частотой опрашиваются и как их погрешности влияют на выполнение маршрута из задания (`задание.md`). Характеристики выбранного IMU приведены в `Avionic.md`.

**Исходные условия проекта:**
- **спутниковая навигация (ГНСС) не используется** — штатный приёмник Mavic 3 Pro в навигационном решении не участвует;
- **на борт можно добавлять любые дополнительные датчики** сверх штатных.

> **Примечание.** DJI не публикует конкретные модели микросхем, установленных в Mavic 3 Pro. Поэтому в модели цифрового двойника инерциальный блок описывается через выбранный аналог — ICM-42688-P, а остальные датчики — через типовые характеристики своего класса. Массы и частоты дополнительных датчиков — оценки по типовым серийным модулям.

## 1. Общая структура

Строго говоря, ИНС — это **инерциальный измерительный блок (IMU)** и **вычислитель**, который по его сигналам рассчитывает ориентацию, скорость и координаты. На БПЛА используется **бесплатформенная ИНС (БИНС)**: датчики жёстко закреплены на корпусе, а гиростабилизированная платформа заменена математическим пересчётом из связанной системы координат в навигационную.

Автономная БИНС на MEMS-датчиках быстро накапливает ошибку: за минуту полёта ошибка положения достигает сотен метров (раздел 8). Обычно её ограничивают по ГНСС, но по условию проекта ГНСС недоступна. Поэтому БИНС работает в составе **комплексной навигационной системы**, где коррекцию дают датчики двух типов:

- **относительные** — измеряют скорость или смещение. Ошибка накапливается, но в десятки раз медленнее, чем у чистой БИНС;
- **абсолютные** — определяют координату по известному ориентиру или карте и обнуляют накопленную ошибку.

Для полёта длительностью 25–43 минуты без ГНСС нужны оба типа.

```
                 ┌────────────────────── БИНС ──────────────────────┐
  Гироскоп  ───► │  Алгоритм ориентации ─► Пересчёт ускорений        │
  Акселерометр ─►│  (кватернион)            в навигационную СК       │
  Термодатчик ─► │                          ─► Интегрирование V, R   │
                 └───────────────────────────────┬───────────────────┘
                                                 │ прогноз
                                                 ▼
  ОТНОСИТЕЛЬНАЯ КОРРЕКЦИЯ               ┌──────────────────────┐
  Визуально-инерциальная одометрия ───► │                      │
  Оптический поток ──────────────────►  │                      │
  Доплеровский радар (ДИСС) ─────────►  │   Фильтр Калмана     │ ──► φ, θ, ψ, V, R
                                        │   (коррекция ошибок  │     в регулятор
  АБСОЛЮТНАЯ КОРРЕКЦИЯ                  │    и оценка дрейфов) │     и в логгер
  Сопоставление снимков с картой ────►  │                      │
  Навигация по рельефу ──────────────►  │                      │
  Опознавание ориентиров ────────────►  │                      │
                                        │                      │
  КУРС И ВЫСОТА                         │                      │
  Магнитометр ───────────────────────►  │                      │
  Барометр, ToF, радиовысотомер ─────►  └──────────────────────┘
```

Состав системы по уровням:

| Уровень | Элементы | Роль |
|---|---|---|
| Чувствительные элементы БИНС | гироскоп, акселерометр, термодатчик (IMU, 2 шт.) | первичные инерциальные измерения |
| Относительная коррекция положения | стереокамеры (VIO), модуль оптического потока, доплеровский радар | скорость и смещение без ГНСС |
| Абсолютная коррекция положения | надирная камера + бортовая карта, радиовысотомер + цифровая карта высот, опознавание ориентиров | обнуление накопленной ошибки координат |
| Курс | магнитометры (2 шт.), зрение, солнечный датчик курса (опция) | удержание курса |
| Высота | барометр, ToF-датчик, радиовысотомер | высота над точкой взлёта и над поверхностью |
| Вычислитель | полётный контроллер + навигационный компьютер для обработки изображений | алгоритм БИНС, фильтр Калмана, обработка изображений |
| Регистрация | бортовая память (логгер) | запись телеметрии для цифрового двойника |

## 2. Чувствительные элементы БИНС

### 2.1. Трёхосный гироскоп

**Измеряет:** угловые скорости вращения корпуса вокруг связанных осей — $\omega_x$ (крен), $\omega_y$ (тангаж), $\omega_z$ (рыскание).

**Назначение:** интегрирование угловых скоростей даёт ориентацию дрона — углы крена $\varphi$, тангажа $\theta$ и курса $\psi$. Ориентация нужна, чтобы:
- удерживать дрон в горизонте (стабилизация);
- выполнять повороты по рысканию при облёте препятствий;
- правильно пересчитывать показания акселерометра в навигационную систему координат.

**Тип:** MEMS-гироскоп вибрационного (кориолисова) типа. В ICM-42688-P резонансная частота чувствительного элемента равна 25–29 кГц, что значительно выше частоты вибраций от моторов и винтов.

**Ключевые параметры (ICM-42688-P):**

| Параметр | Значение |
|---|---|
| Диапазон измерений | до ±2000 °/с |
| Разрядность АЦП | 16 бит |
| Начальное смещение нуля | ±0.5 °/с |
| Температурный дрейф нуля | ±0.005 °/с/°C |
| Спектральная плотность шума | 0.0028 °/с/√Гц |
| Погрешность масштабного коэффициента | ±0.5 % |
| Перекрёстная чувствительность | ±1.25 % |

Максимальная угловая скорость Mavic 3 Pro по рысканию — около 200 °/с, поэтому даже диапазон ±250 °/с перекрывает её с запасом. В модели принят диапазон ±2000 °/с, чтобы гарантированно исключить насыщение при резких манёврах и порывах ветра.

### 2.2. Трёхосный акселерометр

**Измеряет:** кажущееся ускорение (удельную силу) $a_x, a_y, a_z$ — сумму линейного ускорения дрона и реакции на силу тяжести.

**Назначение:**
- после вычитания $g$ и пересчёта в навигационную СК — двойное интегрирование для получения скорости $V$ и координат $R$;
- в неподвижном состоянии и в режиме висения — определение крена и тангажа по направлению вектора $g$ (начальная выставка и коррекция дрейфа гироскопа);
- оценка скорости относительно воздуха по аэродинамической модели квадрокоптера (раздел 3.4);
- обнаружение ударов, касания земли и свободного падения.

**Ключевые параметры (ICM-42688-P):**

| Параметр | Значение |
|---|---|
| Диапазон измерений | до ±16 g |
| Разрядность АЦП | 16 бит |
| Начальное смещение нуля | ±20 мg ≈ ±0.196 м/с² |
| Температурный дрейф нуля | ±0.15 мg/°C |
| Спектральная плотность шума | 65–70 мкg/√Гц |
| Перекрёстная чувствительность | ±1 % |

### 2.3. Термодатчик

Встроен в кристалл IMU. Измеряет температуру чувствительных элементов. Нужен для температурной компенсации: смещения нуля и масштабные коэффициенты гироскопа и акселерометра зависят от температуры, а электроника дрона нагревается в полёте. Рабочий диапазон Mavic 3 Pro по данным DJI — от −10 до +40 °C.

### 2.4. Резервирование IMU

Без ГНСС отказ единственного IMU означает потерю навигации, поэтому в проекте принято **два IMU** с независимыми погрешностями. Это даёт:
- контроль целостности (сравнение показаний, отбраковка отказавшего датчика);
- снижение случайной составляющей шума при усреднении примерно в $\sqrt{2}$ раз.

> **Вариант повышения точности.** Вместо второго ICM-42688-P можно поставить IMU тактического класса (например, серии ADIS164xx). Его нестабильность смещения нуля — единицы °/ч против единиц °/с у потребительских MEMS, что многократно замедляет рост ошибки при пропаданиях коррекции. Цена — масса и стоимость.

## 3. Относительная коррекция положения (скорость и смещение)

### 3.1. Визуально-инерциальная одометрия (VIO) — штатная

**Датчики:** всенаправленная бинокулярная система камер Mavic 3 Pro + IMU.

**Принцип:** на последовательных стереокадрах отслеживаются характерные точки. По их смещению с учётом угловых скоростей IMU определяются перемещение и скорость дрона по трём осям. Стереопара даёт истинный масштаб без дополнительных датчиков.

**Применение в маршруте:** основной источник коррекции на всём маршруте, в том числе **под мостом**, а также обнаружение и облёт 7 препятствий.

**Точность:** по спецификации DJI точность висения по зрению — ±0.1 м по вертикали и ±0.3 м по горизонтали. В длительном полёте ошибка VIO накапливается, типично на уровне 1–2 % пройденного пути (оценка по литературе).

**Ограничения:** нужны освещённость и текстура; не работает в темноте, тумане и над однородной поверхностью (вода, снег).

### 3.2. Модуль оптического потока — дополнительный

**Датчики:** направленная вниз камера с высокой частотой кадров + собственный дальномер для масштаба (типовой модуль весит единицы граммов).

**Принцип:** горизонтальная скорость определяется по скорости смещения изображения поверхности и высоте над ней:

$$V_{гор} = \omega_{потока} \cdot h$$

где $\omega_{потока}$ — угловая скорость смещения изображения (с учётом вращения корпуса по гироскопу), $h$ — высота над поверхностью от ToF или радиовысотомера.

**Применение в маршруте:** полёт **на малой высоте по рельефу** — как раз рабочий режим этого датчика. Дублирует VIO по горизонтальной скорости.

**Ограничения:** рабочая высота — до единиц или десятков метров; нужна текстурированная поверхность.

### 3.3. Доплеровский измеритель скорости и сноса (ДИСС) — дополнительный

**Датчики:** малогабаритный радар миллиметрового диапазона (FMCW, 60–77 ГГц), антенна направлена вниз-вперёд.

**Принцип:** по доплеровскому сдвигу частоты сигнала, отражённого от земли, измеряется вектор путевой скорости.

**Зачем нужен:** **не зависит от освещения, тумана, дыма и текстуры поверхности** — закрывает главную слабость VIO и оптического потока. Работает и над водой (хуже, чем над сушей).

**Ограничения:** дополнительная масса (десятки граммов) и энергопотребление.

### 3.4. Аэродинамическая модель квадрокоптера — программная

**Датчики:** акселерометр (дополнительное оборудование не нужно).

**Принцип:** у мультикоптера горизонтальная сила сопротивления винтов приблизительно пропорциональна скорости относительно воздуха, а акселерометр её измеряет:

$$a_{x}^{b} \approx -k_d \, V_{x,\,возд}^{b}, \qquad a_{y}^{b} \approx -k_d \, V_{y,\,возд}^{b}$$

Коэффициент $k_d$ определяется лётными испытаниями.

**Роль:** резервный источник скорости при отказе всех оптических и радиолокационных датчиков. Измеряет скорость относительно воздуха, поэтому ветер даёт ошибку; при этом скорость ветра оценивается фильтром Калмана, пока работают другие датчики.

## 4. Абсолютная коррекция положения

Относительные датчики только замедляют рост ошибки. Чтобы ограничить её на маршруте длиной в километры, нужна абсолютная коррекция — определение координат по заранее известной информации о местности.

### 4.1. Корреляционно-экстремальная навигация по изображению — дополнительная

**Датчики:** надирная (направленная строго вниз) камера с глобальным затвором + **ортофотоплан маршрута** в памяти вычислителя.

**Принцип:** снимок под дроном приводится к масштабу карты (по высоте и ориентации от ИНС) и сравнивается с ортофотопланом в окрестности текущей оценки положения. Положение максимума корреляции — измеренные координаты.

**Точность:** единицы метров, зависит от разрешения карты и контрастности местности.

**Ограничения:** нужны свет и заранее подготовленная карта; хуже работает над однородной местностью и при сильных сезонных изменениях.

### 4.2. Навигация по рельефу — дополнительная

**Датчики:** радиовысотомер + барометр + **цифровая модель рельефа (ЦМР)** в памяти.

**Принцип:** разность барометрической высоты и высоты над поверхностью даёт профиль рельефа под траекторией:

$$H_{рельефа}(t) = H_{баро}(t) - h_{радио}(t)$$

Профиль за последние сотни метров полёта сравнивается с ЦМР, и выбирается положение с наилучшим совпадением (принцип TERCOM).

**Применение в маршруте:** по заданию полёт выполняется **по рельефу на минимальной высоте**, поэтому профиль поверхности измеряется непрерывно. Метод не зависит от освещения и погоды.

**Ограничения:** над плоской однородной местностью точность падает; нужна достаточно подробная ЦМР.

### 4.3. Коррекция по ориентирам — программная (камеры)

**Принцип:** камеры распознают объекты с заранее известными координатами. По их положению в кадре и дальности (стереозрение) вычисляются координаты дрона.

**Применение в маршруте:** на маршруте уже есть готовые ориентиры с известными координатами — **7 препятствий и мост**, расположенные приблизительно равномерно. Это 8 контрольных точек, по которым ошибка обнуляется не реже чем через 1/8 длины маршрута.

### 4.4. Наземные радиомаяки (UWB) — опция

**Датчики:** бортовой UWB-модуль + несколько маяков на земле с известными координатами.

**Принцип:** дальномерная трилатерация с точностью до десятков сантиметров.

**Применение:** локальная высокоточная навигация на ответственных участках — **пролёт под мостом**, точка взлёта и посадки. Требует установки маяков, поэтому на весь маршрут не применяется.

### 4.5. Лидар (SLAM) — опция

Лидар строит трёхмерную карту окружения и определяет по ней положение. Работает в темноте и даёт наилучшее качество облёта препятствий, но масса типового малогабаритного лидара (порядка 250–300 г) сопоставима с третью массы Mavic 3 Pro, что сильно сокращает время полёта. В базовую конфигурацию не входит.

## 5. Курс и высота

### 5.1. Магнитометры (2 шт.)

**Измеряют:** вектор магнитного поля Земли по трём осям.

**Корректируют:** курс $\psi$. Крен и тангаж корректируются по гравитации (акселерометр), а курс так скорректировать нельзя — вектор $g$ вертикален и не несёт информации о направлении на север.

**Почему без ГНСС курс критичен.** С ГНСС курс уточняется по направлению движения, без неё — нет. Ошибка курса прямо переходит в боковое смещение:

$$\Delta Z \approx V \, t \, \sin\Delta\psi$$

При $V = 15$ м/с и $\Delta\psi = 2^\circ$ это около 0.5 м бокового ухода за каждую секунду полёта.

**Ограничения:** искажения от токов моторов и металлоконструкций. **Стальной мост** может искажать показания, поэтому у моста фильтр снижает доверие к магнитометру, а курс удерживается по гироскопу и зрению. Второй магнитометр, разнесённый с первым, помогает обнаруживать искажения.

### 5.2. Дополнительные источники курса

- **VIO** — изменение курса по смещению изображения;
- **ориентиры** — направление на опознанный объект с известными координатами;
- **солнечный (поляризационный) датчик курса** — опция: определяет курс по положению Солнца или по поляризации неба, не подвержен магнитным помехам. Работает только днём.

### 5.3. Барометр — штатный

Измеряет атмосферное давление, по нему рассчитываются высота относительно точки взлёта и вертикальная скорость. Корректирует вертикальный канал БИНС. Используется при **облёте препятствий сверху** и в навигации по рельефу (раздел 4.2). Чувствителен к потоку от винтов и изменениям погоды.

### 5.4. 3D ИК-датчик (ToF) — штатный

Направлен вниз, измеряет высоту над поверхностью на малых высотах (единицы — десятки метров). Используется для полёта по рельефу, посадки и масштаба оптического потока.

### 5.5. Радиовысотомер — дополнительный

Малогабаритный радар миллиметрового диапазона, направленный вниз. По сравнению с ToF имеет **большую дальность** и не зависит от освещения и поверхности (работает над водой, травой, снегом). Нужен для навигации по рельефу (раздел 4.2) и полёта на минимальной высоте.

## 6. Вычислитель и алгоритмы

Обработка разделена между двумя вычислителями:
- **полётный контроллер** — БИНС, фильтр Калмана, управление (жёсткое реальное время);
- **навигационный компьютер** (дополнительный модуль) — обработка изображений: VIO, сопоставление с картой, распознавание ориентиров. Хранит ортофотоплан и ЦМР маршрута.

Задачи:

1. **Предобработка сигналов:** перевод кодов АЦП в физические величины, температурная компенсация, фильтрация вибраций.
2. **Алгоритм ориентации:** интегрирование угловых скоростей в кватернионной форме $\dot{q} = \frac{1}{2} q \otimes \omega$.
3. **Навигационный алгоритм БИНС:**
   - пересчёт ускорения в навигационную СК: $a^n = C_b^n \, a^b$;
   - компенсация силы тяжести: $\dot{V}^n = a^n + g^n$;
   - интегрирование скорости и координат: $\dot{R}^n = V^n$.
4. **Комплексирование:** расширенный фильтр Калмана (EKF). БИНС — модель прогноза; VIO, оптический поток, ДИСС, сопоставление с картой, навигация по рельефу, ориентиры, магнитометр и высотомеры — измерения. В вектор состояния входят **смещения нуля гироскопа и акселерометра** и **скорость ветра** — они оцениваются в полёте.
5. **Контроль целостности:** сравнение резервированных датчиков, отбраковка аномальных измерений (искажённый компас у моста, ложное совпадение карты над однородной местностью).
6. **Выдача результатов** в систему автоматического управления и в логгер.

## 9. Влияние погрешностей на маршрут

### 9.1. Рост ошибки автономной БИНС

Ниже приведены оценки для паспортных смещений нуля ICM-42688-P без калибровки. Они показывают, сколько система может лететь **без какой-либо коррекции** — например, если одновременно отказали все внешние датчики.

**От смещения акселерометра** $b_{a0} = 0.196$ м/с²: $\Delta S \approx \frac{1}{2} b_{a0} t^2$

**От смещения гироскопа** $b_{g0} = 0.5$ °/с через ошибку горизонта: $\delta r \approx \frac{1}{6} g \, b_{g0} \, t^3$

**Ошибка курса:** $\Delta\psi \approx b_{g0} \, t$

| Время без коррекции | $\Delta S$ от акселерометра | $\delta r$ от гироскопа | $\Delta\psi$ |
|:---:|:---:|:---:|:---:|
| 5 с | 2.45 м | 1.78 м | 2.5° |
| 10 с | 9.8 м | 14.3 м | 5° |
| 60 с | 353 м | — (формула малых углов неприменима) | 30° |

Вывод: автономно БИНС на MEMS-датчиках держит точность в пределах метров только единицы секунд. Внешняя коррекция нужна постоянно.

### 9.2. Какой датчик работает на каком участке

| Участок | Особенность для ИНС | Основная коррекция положения | Курс | Высота |
|---|---|---|---|---|
| Прямолинейный полёт по рельефу | малая высота, длинные участки | VIO + оптический поток + ДИСС; периодически — карта и рельеф | магнитометр | ToF + радиовысотомер + барометр |
| Облёт запретной зоны (+20 %) | самый длинный манёвр, накопление ошибки | VIO + ДИСС; сопоставление с картой | магнитометр + зрение | радиовысотомер + барометр |
| 3 облёта сверху (+4 %) | подъём на половину высоты — оптический поток теряет точность | VIO + ДИСС | магнитометр | барометр + радиовысотомер |
| 3 поворота по рысканию (4 %, 5 %, 6 %) | ошибки масштабного коэффициента гироскопа (недоворот/переворот) | VIO + ДИСС | магнитометр + зрение | ToF + барометр |

## 10. Частоты опроса датчиков и объём памяти

(Пункт 4 общего задания.) Частота IMU (200 Гц) и формат кадра взяты из `Avionic.md`. Для остальных датчиков частоты и размеры кадров — **принятые в модели оценки** по типовым значениям для своего класса. В лог пишутся результаты обработки, а не видеопоток камер.

| Датчик / источник | Частота, Гц | Состав кадра | Кадр, байт | Поток, байт/с |
|---|:---:|---|:---:|:---:|
| IMU | 200 | 3 оси × 2 датчика × 2 Б + время 2 Б + температура 2 Б | 16 | 3200 |
| Магнитометр | 50 | 3 оси × 2 Б + время 2 Б | 8 | 400 |
| Барометр | 25 | давление 4 Б + время 2 Б + температура 2 Б | 8 | 200 |
| ToF-датчик | 50 | дальность 2 Б + время 2 Б | 4 | 200 |
| Радиовысотомер | 50 | дальность 2 Б + время 2 Б | 4 | 200 |
| Оптический поток | 100 | поток по 2 осям 2×2 Б + качество 1 Б + дальность 1 Б + время 2 Б | 8 | 800 |
| VIO | 20 | смещение и скорость по 3 осям, время | 24 | 480 |
| ДИСС | 20 | скорость по 3 осям 3×2 Б + время 2 Б | 8 | 160 |
| Сопоставление с картой | 1 | координаты 2×4 Б + точность 2 Б + качество 2 Б + время 4 Б | 16 | 16 |
| Ориентиры | по событию (8 за полёт) | номер, координаты, точность, время | 16 | ≈ 0 |
| **Итого** | | | | **5656** |

**Обоснование частоты IMU через скорость.** При максимальной горизонтальной скорости Mavic 3 Pro $V_{max} \approx 21$ м/с и частоте 200 Гц дрон между отсчётами пролетает

$$\Delta x = \frac{V_{max}}{F} = \frac{21}{200} \approx 0.105 \text{ м},$$

что достаточно для точного описания манёвров облёта и пролёта под мостом. Динамика ориентации квадрокоптера лежит в полосе до десятков герц, поэтому 200 Гц обеспечивают многократный запас по теореме Котельникова.

**Объём памяти** при максимальном времени полёта 43 мин (2580 с):

$$V_{\text{макс}} = 5656 \text{ байт/с} \times 2580 \text{ с} = 14\,592\,480 \text{ байт} \approx 13.92 \text{ МБ}$$

С двукратным запасом:

$$V_{\text{проект}} \approx 27.83 \text{ МБ}$$

Если поставить опциональный лидар (поза 32 байт × 10 Гц = 320 байт/с), поток вырастет до 5976 байт/с, объём — до ≈ 14.70 МБ, с запасом ≈ 29.41 МБ.

Ортофотоплан и ЦМР маршрута хранятся в памяти навигационного компьютера отдельно от логов. Их объём зависит от длины маршрута и разрешения карты.

## 12. Итог

В состав ИНС Mavic 3 Pro для модели цифрового двойника (без ГНСС) входят:

1. **БИНС:** два MEMS-модуля IMU (в модели — ICM-42688-P), каждый с трёхосным гироскопом, трёхосным акселерометром и термодатчиком, у центра масс.
2. **Относительная коррекция положения:** штатная стереосистема (VIO), модуль оптического потока, доплеровский радар (ДИСС), аэродинамическая модель как резерв.
3. **Абсолютная коррекция положения:** надирная камера с ортофотопланом, радиовысотомер с цифровой картой рельефа, опознавание 7 препятствий и моста как ориентиров; UWB-маяки у моста — опция.
4. **Курс:** два магнитометра, зрение, солнечный датчик — опция.
5. **Высота:** барометр, ToF-датчик, радиовысотомер.
6. **Вычислители:** полётный контроллер (БИНС + фильтр Калмана) и навигационный компьютер (обработка изображений, карты).
7. **Логгер:** не менее ≈ 28 МБ для записи телеметрии всех датчиков с двукратным запасом.
